CORE PROJECT SCRIPTS:
─────────────────────

generate_data.py (2.8 KB)
- Generates 105,120 synthetic electricity records
- Creates 2 years of hourly data for 6 buildings
- Injects realistic patterns and 2% anomalies
- Output: electricity_data_simulated.csv

train_model.py (3.5 KB)
- Builds LSTM neural network
- Normalizes features using StandardScaler
- Trains model on synthetic data (30 epochs)
- Evaluates accuracy (R² > 0.85)
- Output: lstm_model.h5, scaler.pkl

detect_anomalies.py (3.5 KB)
- Loads trained model and makes predictions
- Calculates residuals (actual - predicted)
- Detects anomalies using 2-sigma threshold
- Analyzes by building
- Calculates cost impact
- Output: electricity_results.csv

visualize.py (5.0 KB)
- Creates 5 different visualization charts
- Actual vs Predicted line chart
- Anomaly detection scatter plot
- Wastage by building bar chart
- Hourly consumption pattern
- Monthly trend analysis
- Output: 3 PNG image files

dashboard.py (8.0 KB)
- Streamlit web application
- Interactive building selector
- Real-time metrics and charts
- Data table viewing
- CSV download functionality
- Responsive design
- Runs on: http://localhost:8501

❓ COMMON QUESTIONS
═════════════════════════════════════════════════════════════════════

Q: Do I need real electricity data?
A: No! Synthetic data is included and is realistic enough for learning.

Q: Can I run this on Windows/Mac/Linux?
A: Yes! Works on all platforms. Use setup.sh for Linux/Mac, setup.bat for Windows.

Q: How long does it take to run?
A: ~10-15 minutes for complete execution.

Q: Do I need admin/sudo access?
A: Not necessarily, but helpful for clean installation.

Q: Can I run each step separately?
A: Yes! You can run generate_data.py, then train_model.py, etc. independently.

Q: What if I want to run multiple times?
A: CSV files will be overwritten, but model and visualizations are created fresh each time.

Q: Can I use my own data later?
A: Yes! Just replace electricity_data_simulated.csv with your own data in same format.

Q: Will the dashboard update automatically?
A: Yes, if you re-run detect_anomalies.py and refresh the browser.

Q: Is this production-ready?
A: No, this is an MVP for learning. For production, add more validation and security.

Q: Can I modify the code?
A: Yes! All code is open and well-commented for learning purposes.
