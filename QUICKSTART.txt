STEP 1: EXTRACT THE FILES
═════════════════════════
1. Download the ZIP file
2. Extract it to a folder on your computer
3. Open a terminal/command prompt
4. Navigate to the extracted folder

STEP 2: INSTALL PYTHON (If not already installed)
═════════════════════════════════════════════════════
1. Download Python 3.9 or higher from: https://www.python.org/downloads/
2. Install it and add Python to PATH
3. Verify installation:
   python --version

STEP 3: INSTALL DEPENDENCIES
════════════════════════════
Run one of these commands (choose one):

OPTION A (Windows):
   setup.bat

OPTION B (Linux/Mac):
   bash setup.sh

OPTION C (Manual):
   pip install -r requirements.txt

STEP 4: RUN THE PROJECT (Choose one)
═════════════════════════════════════

OPTION A - AUTOMATIC (Recommended for beginners):
   python run_all.py
   
   This will run all steps automatically:
   - Generate data
   - Train model
   - Detect anomalies
   - Create visualizations
   - Launch dashboard

OPTION B - STEP BY STEP (Recommended to understand):
   Step 1: python generate_data.py         (1-2 min)
   Step 2: python train_model.py           (3-5 min)
   Step 3: python detect_anomalies.py      (1 min)
   Step 4: python visualize.py             (1 min)
   Step 5: streamlit run dashboard.py      (Opens in browser)

STEP 5: VIEW RESULTS
════════════════════
The dashboard will open automatically at:
   http://localhost:8501

You can interact with:
✓ Building selector dropdown
✓ Interactive charts
✓ Real-time statistics
✓ Download buttons
✓ Data tables

COMMON ISSUES & FIXES
═════════════════════

Issue: "python not found"
Fix: Install Python from https://www.python.org/downloads/

Issue: "No module named 'tensorflow'"
Fix: pip install tensorflow

Issue: "electricity_data_simulated.csv not found"
Fix: Run python generate_data.py first

Issue: "Streamlit not found"
Fix: pip install streamlit

Issue: Long training time (3-5 minutes)
Fix: This is normal! Don't interrupt it.

Issue: "Out of memory" error
Fix: Close other applications and try again

HOW IT WORKS (In simple terms)
═══════════════════════════════
1. GENERATE DATA
   Creates fake but realistic electricity data
   
2. TRAIN MODEL
   Teaches the AI to predict electricity consumption
   
3. DETECT ANOMALIES
   Compares actual vs predicted
   If difference is too high = WASTAGE
   
4. VISUALIZE
   Creates charts showing findings
   
5. DASHBOARD
   Interactive web interface to explore results
